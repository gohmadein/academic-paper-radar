# JetBrains Mono webfonts

Official, unmodified Regular and Bold WOFF2 files from JetBrains/JetBrainsMono.

Source revision: `19371302b95d218af43299bce79ddbddd0bc364d`

https://github.com/JetBrains/JetBrainsMono/tree/19371302b95d218af43299bce79ddbddd0bc364d/fonts/webfonts

License: SIL Open Font License 1.1, included as `OFL.txt`.

The site serves these assets from its own origin. It does not install the font on the device or contact a font CDN. JetBrains Mono does not include Chinese glyphs; Chinese text uses the installed PingFang SC / Microsoft YaHei / system fallback fonts declared in CSS.
