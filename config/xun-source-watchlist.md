# 机器人文献推荐系统关注清单

整理日期：2026-10-31

关注范围：所有机器人相关文献。纯机构设计类论文按此前约定排除。

推荐层级：**核心**为优先关注来源；**扩展**为持续关注的其他来源；**新刊观察**用于跟踪新期刊；**综合来源**纳入其中的机器人相关论文。层级仅影响关注顺序，不限制研究主题。

### 3.5 跟踪对象说明

- **CUHK MMLab、MMLab@NTU、HKU MMLab**分别登记；**OpenGVLab**独立登记。
- **OpenMMLab**作为视觉工具与项目生态，随相关团队跟踪。

- 企业与综合研究机构跟踪其机器人相关团队和项目。
