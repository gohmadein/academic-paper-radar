# 双语论文卡片与素材契约

日报v2新增必填字段 `summaryEn` 与 `visuals`。`summaryEn` 是同一条100–200字符中文导读的忠实英文翻译，不是另贴原始摘要，也不能增加未经核验的结果。中文标题在上，原始英文标题在下；两种导读始终同时展示。论文ID、日期、选择规则与本机收藏格式不变。

```json
{
  "summaryEn": "A faithful English translation of the Chinese guide...",
  "visuals": {
    "mainFigure": null,
    "figureNote": "没有可核实主图时，填写真实原因。",
    "institutions": [],
    "authors": []
  }
}
```

## 本地素材对象

下列字段全部必填，仅在素材真实核验并允许相应展示时才引用。无法满足时用null，不猜链接、照片或许可。

| 字段 | 说明 |
| --- | --- |
| kind | figure / institution-logo / author-portrait，不能用机构图标充当人像 |
| path | `assets/papers/`、`assets/institutions/` 或 `assets/authors/` 下的安全相对路径，PNG/JPEG/WebP/SVG；不含..或远程地址 |
| sha256 | 最终打包字节的64位小写SHA256，不是原始大图的哈希 |
| width / height | 最终图像真实尺寸，正整数；SVG保留正确视图比例 |
| sourceUrl | 实际原始图像/材料来源；页面运行时不从此地址加载图片 |
| evidenceUrl | 能证明素材、作者身份或所属论文的官方原始页面 |
| verifiedAt | 真实核验日期或带时区时间戳，不捏造精度 |
| credit | 简洁图注/归属，随图展示 |
| rights | 如实保留许可、商标、版权或未核实的边界；arXiv非独占发布许可不是通用再利用许可 |
| displayPolicy | open-license / official-brand / attributed-thumbnail；这些是展示记录，不能将未知许可写成开放许可 |
| background | light / dark / transparent；白色标志可用compact dark backing，整体仍保持浅色主题 |
| altZh / altEn | 忠实的替代文字，不捏造图中结论 |

主图只使用论文/作者项目的实际主图或概览图，保持内容与比例；优化尺寸不能裁掉关键图例。理论论文没有主图时显示“暂无可核实主图”，不能生成假图。不要为当前空位从无关论文借图。

## 论文署名机构

`institutions` 的每项为 `{name, logo, authorNames, evidence, note}`。`logo` 为素材对象或null；`authorNames` 仅列论文实际作者，不能根据现雇主猜所属关系。`evidence` 为 `[{url,claim,checkedAt}]`，指向本篇论文或作者明确署名来源。`note` 说明署名/展示限制。未核验机构不填入，缺少可展示logo时以名字和明确的“文字标识”占位。

ASU等有外部许可限制的标志，以及许可未核实且要求保守展示的标志，应保持logo=null。受限文件不得放进部署资产目录；来源审阅包留在仓库之外。机构标志不是合作背书，不增加认证勾。

## 作者肖像

`authors` 的每项为 `{name,portrait,note}`，`name` 必须精确对应原始作者名单。`portrait` 为真实人像素材或null，来源必须明确把该照片标为这个作者；同校、同组或相似姓名不构成证明。没有官方可靠肖像时，可不填该作者的素材记录，界面自动显示姓名文字与完整姓名。

完整作者名单始终可访问；卡片先展示部分作者并可展开其余作者。头像不是机构logo，不使用假人脸或AI生成肖像。

## 打包、校验与云端发布

先把审核后的字节放入 `path`，再导入规范日报。`npm run check` 校验本地存在性、SHA256与尺寸；SVG拒绝脚本、动态元素和未打包外部依赖。构建只拷贝被日报引用且通过校验的研究素材，另保留站点Logo和字体，不会整包发布来源审阅档案。

`node scripts/ingest.mjs normalized.json --plan` 继续返回3个JSON文件的 `files`，另外返回 `assetFiles`（path、encoding=base64、content、sha256）。云端可逐个用GitHub `create_blob` 的base64编码建立二进制blob，再将返回SHA与3个JSON文件一起加入一次 `create_tree` / `create_commit` / 带expected_sha的分支更新。不要把base64当UTF-8图像文件提交，也不要先发布引用缺失文件的日报。

图片以带内容版本的同源URL加载，主图object-fit:contain、声明尺寸并保留固定显示框。加载失败回退到同尺寸提示，避免版式跳动。卡片分享仅包含公开论文定位，不含本机收藏或已读列表；优先系统分享，再复制链接，权限不可用时提供可手动复制的文本。没有点赞、浏览量或认证计数。

外部每日调度沿用原计划；搜集流程需为新记录提供英文翻译、真实素材及证据，缺失情况如实说明。此工程不创建第二个调度或后端。

## 大学与机构标识

大学展示官方提供的完整校徽、盾徽或紧凑身份符号（如官方Block I）；不要求只能使用受限仪式印章，也不把字母身份符号称为传统校徽。不使用长字标、自造首字母或从组合标志裁出的图形代替。研究机构和公司使用本机构的官方标识，不用上级组织或相近机构标识替代。标识约32px，object-fit:contain，名称紧邻展示；不可拉伸、重绘或任意改色。缺少可核验且可展示的校徽时只显示机构名称，并保留缺失或使用限制的说明；不显示仿官方首字母徽章。作者头像规则不变。

每项机构记录必填 institutionType（university/research-institute/company/chair）及 markType（emblem/compact-symbol/organization-mark/none）。大学可用emblem或compact-symbol，其他机构用organization-mark；none对应logo=null。缺失标识只保留机构名称。

本期紧凑大学标识：Illinois官方Block I；清华章程PDF第15页嵌入JPEG校徽（554×385，原样提取，未重绘/裁切）；Harvard官方Veritas盾徽；Georgia Tech官方GT、Northeastern官方N和UCSD官方主页三叉戟。ICO仅转为PNG保留完整图案。后四者的紧凑身份符号不称为仪式印章。Penn独立盾徽、UMD/ASU及Laval受限展示保持文字名称。精确源地址、类型、权利说明和字节哈希随每篇visuals.institutions保存。

透明标识审计：机构图片容器不设置灰底、深色底板、边框、阴影或滤镜；图片按比例完整显示。实际PNG需有有效透明通道，SVG不得含不必要的实心底板，不能只用CSS掩盖图片自带底色。无可靠肖像时仅列作者姓名，不生成首字母圆圈；已核验的真实头像保留。

当前透明素材例外：清华官方章程JPEG含白底，保持原样在白色卡片上显示，metadata.background=light，不称为alpha透明。任何改变校徽文字、绳纹或几何的抠图候选不得使用。UMD使用官方完整Informal Seal透明原图，Amazon FAR显示官方Amazon母公司透明标志并注明非FAR专属Logo；UCSD旧favicon为蓝底，改为名称展示。其余标识原SVG/PNG透明通道与容器分别核验。

## 可复用署名机构库（2026-10-31）

`data/institutions.json` 是机构标识的唯一登记库：稳定 ID、官方名称、别名、机构类型、真实标识类型、核验状态、透明/不透明背景，以及素材路径、SHA256、来源、核验时间、署名与使用条件。大学只使用真实官方校徽或紧凑身份符号；研究所、企业和讲席不可冒充大学。清华官方白底原图属于明确记录的不透明例外，不做 AI 重绘或破坏性抠图。

每次推送继续保持现有双语卡片、中文导读的英文翻译、真实论文主图和完整署名证据要求。先按名称/别名查库，再复用现有文件及哈希；不得每期重复搜索、下载、改名存储相同素材。`ingest` 自动解析并回填已核验标识，但绝不从库中推断作者所属单位，论文的 `authorNames` / `evidence` / `note` 仍必须独立核实。新机构只追加一次 `needs-verification` 条目，不信任输入中未经登记的新图；核验官方来源与使用条件后才将登记状态改为 `verified`。无图时仅显示机构名称。更新已存标识后，应同步受影响日报的标识快照及 `institutionId`，保留原署名证据，运行全量校验。

机构库与日报、论文身份库、索引和新素材一起原子发布。验证器检查 ID、别名、重复文件、路径/哈希、文件尺寸以及所有日报引用的一致性。已登记但暂未出现在筛选结果中的素材仍保留在构建产物，供后续复用。

主页面横向标识库只展示当前筛选论文的署名机构；按钮、触摸/触控板、左右方向键及 Home/End 手动浏览，无自动滚动、闪烁或全局动效。展开来源可查看官方证据与权利说明，不表达机构背书。存储复用由本地版本化素材与登记库实现，不由滚动效果实现；相同哈希 URL 允许浏览器复用 HTTP 缓存，但不承诺刷新时零网络请求。

## arXiv公告同等署名标识要求

所有arXiv公告卡同样核对论文署名并展示可核验的真实校徽/机构标志，不再有无校徽豁免；只有主图仍省略。公告的机构ID引用 `data/institutions.json`，而独立论文/作者署名证据存于公告 `affiliations`。标识来源证明和论文署名证明不可相互替代。不得因摘要读过就声称知道署名单位；未获得可靠正文署名证据须标为未核验，并保留进一步核验入口。

### 2026-11-02 本次修复核验结果

机构库252个独立机构，78项已有可展示的真实标识（原14项原字节保留，新增64项）；174项保留具体官方入口、访问/素材/使用限制原因，并非已全部补齐。UCAS与ETH的同机构拼写变体合并为别名，未改变任何论文ID。五个新大PNG仅无损转为WebP：尺寸与RGBA逐字节一致，不缩放、不裁切、不改色。

28篇精选共54项署名引用：18篇至少显示一个标识，13篇全部署名机构都有标识。142篇公告共369项署名引用：137篇机构集合完整核实，2篇部分核实，3篇官方论文未能确认署名单位；74篇至少一个标识，16篇所有署名机构都有标识。这些是本次核验时点的计数，不代表之后新增论文仍具有相同比例。公告主图仍不展示。

不得为填满空缺而从邮箱域名、作者当前单位、通用图标或相似机构推断。明确外部使用限制、最小显示尺寸不符、仅有长字标/带不合适底板的App图标、无可核实官方素材等情况，继续显示真实机构名称；需要授权的素材不打包到网站。
