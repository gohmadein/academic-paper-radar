# 宽主题导航（展示层）

研究主题使用 `lib/topics.js` 的 8 个固定分组：感知与导航、操作与控制、机器人学习、具身智能与模型、机器人系统与评测；知识图谱与推理、数据库与更新、数据理论与溯源。

- 只展示当前人物的论文实际涉及的分组；“全部方向”取并集。迅与驴可共享机器人主题，但人物成员资格只来自原有 `profiles`，不由主题推断。李的主题不会仅因关键词巧合出现在迅的分组中。
- 一篇论文可属于多个宽主题。优先用原始细标签匹配，未命中时尝试中英文标题；仍未命中的已分人物论文进入该领域的宽泛兜底组（机器人系统与评测 / 数据库与更新）。未来收录无需为每个细标签新增导航按钮；若出现新常用术语，在对应正则中补充中英文同义词并添加测试。
- 此模块只用于浏览和过滤，**不是选文白名单**。不改变迅的机器人全方向收录范围、不修改原始 `tags`、人物定义、配额或选文规则，也不要求 ingest 改写任何论文。模块是无依赖纯函数，可由浏览器、测试或 ingest 预览复用。
- 宽主题链接保留现有 `tag` 参数，值为稳定的 `topic:<id>`。旧的 `tag=力觉` 等链接仍精确筛选细标签，并仅额外显示当前激活的“关键词：力觉”，不展开全部细标签。卡片/详情及关键词搜索仍保留原标签。
- 切换人物时，只有在目标人物中没有匹配论文的主题/旧标签才清空；搜索、日期和阅读状态不变。Back/Forward 恢复原状态。书签页点主题不退出书签视图。
- 主题可选项基于当前人物的全部档案（含历史出现记录），不随搜索、日期、阅读状态或书签结果忽隐忽现；这些条件仍共同作用于结果。

验证：`npm run check`。`tests/topics.test.mjs` 覆盖分组、未来术语兜底、多人物隔离、旧链接、细标签搜索与组合筛选；`tests/sidebar.test.mjs` 在应用 DOM harness 中验证主题数量、人物切换、历史、书签和归档。
